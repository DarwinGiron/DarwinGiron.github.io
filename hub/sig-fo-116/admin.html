Cómo se responde

Cada pregunta se contesta Sí, No o N/A (no aplica). El % de cada sección es Sí / (Sí + No) — un "N/A" ni suma ni resta. Las secciones y sus grupos (Personal, Instalaciones, Baños…) son fijos; lo que se edita aquí son las preguntas dentro de cada uno.
